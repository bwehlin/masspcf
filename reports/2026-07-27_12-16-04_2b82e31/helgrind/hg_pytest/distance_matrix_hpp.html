22  /// Lower-triangular compressed distance matrix (zero diagonal, nonnegative entries).
23  ///
24  /// Stores n*(n-1)/2 elements for an n×n symmetric matrix with
25  /// implicit zeros on the diagonal.
26  /// For i != j, element (i, j) maps to storage index
27  /// max(i,j)*(max(i,j)-1)/2 + min(i,j).
28  ///
29  /// A matrix may also be an *indexed view*: it shares another matrix's buffer
30  /// and selects a subset of points through an attached index set, so size() and
31  /// operator()(i, j) report the principal submatrix over those indices. This lets
32  /// a tensor of subsampled distance matrices store one shared source plus small
33  /// index arrays instead of re-storing every sub-matrix. Access through
34  /// size()/operator() is transparent to indexing, so consumers need no special
35  /// case. Writing to an indexed view is copy-on-write: the view detaches by
36  /// materializing in place first, leaving the shared source untouched.
37  /// Tensors of matrices serialize views
38  /// natively (each distinct source stored once, see tensor_io.hpp); a
39  /// *standalone* view is written as its materialization.

145    [[nodiscard]] EntryProxy operator()(size_t i, size_t j)
146    {
147      // Copy-on-write: a write detaches an indexed view by materializing it in
148      // place first, so the shared source buffer is never touched.
149      if (is_indexed())
150        *this = materialize();
