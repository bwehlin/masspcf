16  /// A point cloud of shape (n_points, dim).
17  ///
18  /// A PointCloud either owns its coordinates or is an indexed view: it shares
19  /// another cloud's coordinate buffer and selects rows through an attached
20  /// index set. Access via n_points()/dim()/operator()(i, j) is transparent to
21  /// which mode it is in, so consumers need no special case. This
22  /// lets a tensor of subsamples store one shared source plus small index arrays
23  /// instead of re-storing every (possibly high-dimensional) point.
24  ///
25  /// Deliberately not a Tensor<T>: the raw coordinate storage and the selected
26  /// points disagree for indexed views, so tensor-level access has no single
27  /// meaning here. Use the cloud-level members for the selected points, or
28  /// coords() to reach the underlying storage explicitly.

115    /// Returns the coordinates as-is when not indexed.
116    [[nodiscard]] Tensor<T> materialize() const
117    {
118      if (!is_indexed())

123      const size_t n = n_points();
